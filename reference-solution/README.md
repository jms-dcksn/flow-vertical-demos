# Reference solution

[`claims-process-flow.md`](claims-process-flow.md) is the architectural and storytelling baseline for every domain demo in this repository.

Use [`domain-demo-spec-template.md`](domain-demo-spec-template.md) to turn that
baseline into a concise, scored specification in each domain folder.

It is based on an inspected Studio Web export of the FNOL claims reference solution. It separates evidence from that export from the stricter target standard for new demos, including the three Data Fabric-backed coded process-app demos.
